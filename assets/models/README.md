# Background removal model

`u2netp.onnx` is the lightweight U²-NetP model used by the background removal worker. It runs locally with ONNX Runtime Web.

- [U²-Net project](https://github.com/xuebinqin/U-2-Net)
- [ONNX model from the rembg release](https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx)
